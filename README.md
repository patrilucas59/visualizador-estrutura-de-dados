# Visualizador de Estruturas de Dados

Aplicação interativa para visualizar estruturas de dados clássicas (Pilha, Fila e Árvore Binária de Busca) em tempo real, à medida que elementos são adicionados e removidos.

## Sobre o projeto

Este é um projeto de estudo criado para praticar **Next.js** (App Router) e reforçar conceitos fundamentais de algoritmos e estruturas de dados.

## Estruturas implementadas

- **Pilha (Stack)** — LIFO, o último elemento inserido é o primeiro a ser removido
- **Fila (Queue)** — FIFO, o primeiro elemento inserido é o primeiro a ser removido
- **Árvore Binária de Busca** — inserção recursiva respeitando a regra: valores menores à esquerda, maiores à direita

## Tecnologias

- [Next.js](https://nextjs.org) (App Router)
- React
- TypeScript
- Tailwind CSS

## Rodando localmente

```bash
git clone https://github.com/patrilucas59/visualizador-estrutura-de-dados.git
cd visualizador-estrutura-de-dados
npm install
npm run dev
```
